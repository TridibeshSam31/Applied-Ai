## Reading guidance
1. Read the current MCP specification before relying on protocol details.
2. Read the Python SDK README/examples for the version pinned in your project.
3. Confirm the host supports the selected transport and capabilities.
4. Treat blogs/videos as supplementary explanations, not protocol sources of truth.
5. Record the date and SDK version you tested when specification pages change.
